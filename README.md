# Cyanwoods Cask

## How do I install these formulae?

`brew install cyanwoods/cask/<formula>`

Or `brew tap cyanwoods/cask` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "cyanwoods/cask"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
